# Project-Aura

A text-based RPG adventure built in Python, focused on strategy.

## The Core Stats
The mechanics of this world are governed by six custom attributes:
* **Forza**
* **Agilità**
* **Resistenza**
* **Divinazione**
* **Ingegno**
* **Fortuna**
